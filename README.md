# Jaffier — Network Engineer Portfolio

Interactive Next.js portfolio with a Dragon Isle 3D hero world, terminal UI, field-project case studies, experience timeline, skills, certification, education, and contact sections.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Dragon Isle controls

- Drag: rotate the world
- Scroll: zoom
- Click the castle: Experience
- Click a tower: Skills
- Click the crystal: Certification
- Click the flag: Education
- Click the beacon: Contact
- Click the dragon: About

The 3D scene uses procedural Three.js geometry and does not depend on game assets.
